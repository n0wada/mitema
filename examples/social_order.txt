---
架空の高校で、同じくらいの成績の二人が進路を考えている。
二人の最終的な選択は、まだ決めない。
理論の節は、この場面を読むための着眼点である。
---
[[進路選択と教育格差]]

[場面]
生徒A = 家族に大学進学の経験がある高校生
生徒B = 進学に伴う家計の負担を気にかけている高校生
生徒A -> 同程度の成績
生徒B -> 同程度の成績
進路選択 -> [大学進学, 就職] # この場面で考える選択肢

家族A -[進学経験を伝える]-> 生徒A
家族B -[家計の見通しを伝える]-> 生徒B
教師 -[進路面談する]-> 生徒A
教師 -[進路面談する]-> 生徒B

[それぞれに見えるもの]
view 生徒A {
  大学進学 -> [関心, 家族の助言]
  奨学金 -> 利用可能性?
}
view 生徒B {
  大学進学 -> [関心, 家計への負担]
  就職 -> 早い収入
  奨学金 -> 利用可能性?
}

[ブルデューの読み]
資本 > [経済資本, 文化資本, ブルデューの社会関係資本]
文化資本 -> [学校文化への親しみ, 学歴資格]
経済資本 -> 学費の負担可能性
ブルデューの社会関係資本 -> 人脈を通じて得られる資源
進路選択 -> 家庭が利用できる資本

[ブードンの読み]
出身階層 -> [一次効果, 二次効果]
一次効果 -> 成績の差
二次効果 -> 同じ成績での進路選択の差
進学費用 + 成功の見込み + 将来への期待 -> 進路選択
# 二次効果は、制約の異なる状況での選択を考えるための概念

[コールマンの読み]
コールマンの社会関係資本 -> [義務と期待, 情報経路, 規範]
家族と学校の関係 -> 進学情報の伝わり方?

[読み比べと問い]
ブルデューの社会関係資本 <> コールマンの社会関係資本
# 同じ「社会関係資本」でも、何を説明するかを区別して読む

進路選択 -> [家庭の資源, 学校の情報, 本人の判断]
同程度の成績 + 異なる家庭資源 -> 異なる進路?
奨学金情報 -[届く]-> 生徒B?
